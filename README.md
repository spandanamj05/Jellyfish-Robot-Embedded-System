# Jellyfish-Robot-Embedded-System
Arduino-based jellyfish robot with IR remote control and PWM pump management

## Overview
This project is a beginner-level embedded systems robot inspired by jellyfish movement using Arduino.

The robot is controlled using an IR remote and uses PWM-controlled pumps for directional swimming movement.

---

## Features
- IR remote-based movement control
- Straight, left, and right swimming modes
- PWM motor/pump speed control
- Soft-start mechanism to reduce sudden current spikes
- RGB LED status indication
- Battery voltage monitoring
- Sensor data acquisition

---

## Technologies Used
- Arduino IDE
- Embedded C/C++
- PWM control
- IR communication

---

## Hardware Components
- Arduino board
- IR receiver module
- Water pumps
- RGB LEDs
- Battery module
- Flex sensors
- Temperature sensor
- Depth sensor

---

## Working Principle
The system receives commands from an IR remote and controls pump speed and direction using PWM signals.

A soft-start algorithm gradually increases pump speed to improve stability and reduce sudden current draw.
